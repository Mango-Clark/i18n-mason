# `i18n-mason.toml` v1

English: [configuration.md](configuration.md)

이 파일은 **제품에서 지원하려는 로케일 식별자**를 기록합니다. 프레임워크 설정과 의도적으로 분리되어 있습니다. 런타임을 설치·설정하거나 로케일 선택 방식과 메시지 저장 위치를 지정하지 않습니다.

## 파일 만들기

대상 저장소의 루트에 `i18n-mason.toml`을 둡니다. 아래 예시 값을 제품에서 실제 사용하거나 지원하려는 정확한 식별자로 바꿉니다.

```toml
version = 1
default_locale = "en-US"
locales = ["en-US", "fr-FR"]
```

`default_locale`은 `locales`에 정확히 포함되어야 합니다. v1에서 로케일 식별자는 불투명한 문자열입니다. 검증기는 표기와 순서를 유지하며 값이 유효한 BCP 47 태그인지 판정하지 않습니다. 이 파일을 통과시키려고 `en`을 `en-US`로 바꾸거나 공개·레거시 ID를 정규화하지 마세요. 먼저 제품 계약을 확인합니다.

## 스키마

| 키 | 형식 | 필수 | 의미 |
| --- | --- | --- | --- |
| `version` | 정수 | 예 | 스키마 버전. v1은 `1`만 허용합니다. |
| `default_locale` | 비어 있지 않은 문자열 | 예 | 의도한 제품 기본 로케일. `locales`의 항목과 정확히 일치해야 합니다. |
| `locales` | 비어 있지 않은 서로 다른 문자열의 배열 | 예 | 지원하려는 로케일 식별자. 표기와 순서를 유지합니다. |

위 세 루트 키만 사용할 수 있습니다. v1에 라우트, 프레임워크, 카탈로그 경로, fallback 규칙 또는 추측에 기반한 앱별 설정을 추가하지 않습니다. 구현 세부 사항은 대상 코드베이스에서 조사합니다.

## 구문 검증

이 저장소의 루트 예시는 다음과 같이 확인합니다.

```sh
npm run validate
```

다른 위치의 파일을 검사할 때는 스크립트에 경로를 전달합니다.

```sh
node scripts/validate-config.mjs path/to/i18n-mason.toml
```

포함된 검증기는 일반 공백, 전체 줄·줄 끝 주석, 이스케이프 없는 기본 큰따옴표 문자열, 한 줄·여러 줄 배열을 지원합니다. 테이블·이스케이프 문자열을 포함한 미지원 TOML 구문, 알 수 없거나 중복된 키, 필수 키 누락, 중복·빈 로케일, 목록에 없는 기본 로케일과 `1` 이외의 버전은 거부합니다. 이 검증기는 범위를 제한한 v1 파서이며 일반 TOML 구현이 아닙니다.

예를 들어 아래 설정은 기본 로케일이 목록의 어떤 항목과도 정확히 일치하지 않아 거부됩니다.

```toml
version = 1
default_locale = "en-US"
locales = ["en", "fr"]
```

의도한 공개·제품 로케일 ID를 확인한 뒤 설정을 수정하세요. 검증기는 불일치를 보여주어야 하며 제품 로케일 이름을 대신 결정하지 않습니다.

## 의도와 구현 비교

검증 통과는 파일이 작은 스키마에 맞다는 뜻일 뿐입니다. 번역 존재 여부, 라우트 동작, fallback 정확성이나 런타임의 전체 로케일 지원을 증명하지 않습니다.

활성 코드 경로, 리소스, 테스트, 생성 스크립트, 배포 설정과 관련 제품 문서를 조사해 TOML과 비교합니다. 차이는 마이그레이션 진행, 레거시 식별자, 환경별 설정 또는 별도 모노레포 범위 때문일 수 있습니다. 설정이나 구현을 조용히 고치지 않습니다. 근거로 제품 의도를 알 수 없고 답에 따라 설계가 달라질 때만 사용자에게 묻습니다.

## 이 저장소의 로케일 범위

이 저장소에서 루트 계약은 설명 문서에 적용됩니다. 영어(`en-US`)가 정본이고 한국어(`ko-KR`)는 짝을 이루는 문서로 관리합니다. 실행 시 읽는 스킬은 명시적으로 영어를 유지합니다. 코드, 테스트와 기계가 사용하는 파일은 이 문서 계약에 포함되지 않습니다.
